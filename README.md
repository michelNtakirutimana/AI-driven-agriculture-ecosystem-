AI-DRIVEN AGRICULTURE ECOSYSTEM (ADAE)
​Project Overview
​The AI-Driven Agriculture Ecosystem is an integrated software solution designed to bridge the gap between smallholder farmers and modern agricultural intelligence. By combining a robust mobile ledger system with a localized Kinyarwanda-native AI, the platform automates cooperative logistics while providing real-time, data-driven agronomic support.
​Key Technical Features
​Localized AI Engine: Integration of a Large Language Model (LLM) fine-tuned for Kinyarwanda dialects to provide pest diagnostics and soil health advice.
​Digital Ledger (Offline-First): Built with SQLite and Kivy to ensure cooperative clerks can record transactions in remote areas without stable internet.
​Automated SMS Gateway: Real-time notification system for farmers providing transparent digital receipts and weather alerts.
​Data Visualization Dashboard: A React/Python-based dashboard for cooperative managers to monitor yield trends and financial health.
​Tech Stack
​Frontend: Kivy / Python (for Cross-platform mobile compatibility)
​Backend: FastAPI / Python
​Database: SQLite (local) / PostgreSQL (cloud sync)
​AI Integration: OpenAI API / Custom Fine-tuned Llama models
​DevOps: Git/GitHub for version control
